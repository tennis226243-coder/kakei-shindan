# 家計の健康診断（iPhoneホーム画面版・夫婦で共有／スマホでアップロードしやすい版）

フォルダを使わず、すべてのファイルを同じ場所に置く版です。

## 1. Firebaseの準備（夫婦で共有するため・無料）
1. https://console.firebase.google.com/ を開き、「プロジェクトを作成」（名前は自由。Googleアナリティクスはオフで可）
2. 左のメニュー「構築」→「Authentication」→「始める」→「ログイン方法」で **匿名** を有効にする
3. 「構築」→「Firestore Database」→「データベースを作成」→ 場所は **asia-northeast1（東京）**、「本番環境モード」で作成
4. Firestoreの「ルール」タブを開き、このフォルダの **firestore-rules.txt** の中身を全部貼り付けて「公開」
5. 「プロジェクトの概要」の歯車 →「プロジェクトの設定」→「マイアプリ」で **</>（ウェブ）** を選んでアプリを登録（Hostingは不要）
6. 表示された firebaseConfig の apiKey・authDomain・projectId・appId を、**firebase-config.js** に貼り付けて保存
7. 「Authentication」→「設定」→「承認済みドメイン」に **（ユーザー名）.github.io** を追加

※ 無料プラン（Spark）のままで使えます。クレジットカードの登録は不要です。
※ firebase-config.js の中身は公開されても問題ない情報です（データはルールで守られます）。

## 2. GitHub Pagesで公開
1. GitHubで新しいリポジトリ（Public）を作る（例：kakei-shindan）
2. このフォルダの中身をすべてアップロード
3. Settings → Pages → Branch を「main」「/ (root)」にして Save
4. 数分後に https://（ユーザー名）.github.io/kakei-shindan/ で開けます

## 3. iPhoneのホーム画面に追加
1. 上のURLをSafariで開き、共有ボタン →「ホーム画面に追加」
2. ホーム画面のアイコンから開いて、かんたん入力を済ませる

## 4. 夫婦で共有する
1. アプリの「共有」タブを開くと、招待コードとQRコードが表示されます
2. 奥様のiPhoneのカメラでQRコードを読み取る → 開いたページで自動で同じ家計に参加
3. 奥様もそのページを「ホーム画面に追加」し、ホーム画面のアイコンから開く
   （Safariで開いたときとホーム画面から開いたときは別扱いなので、ホーム画面版で参加できていない場合は「共有」タブからコードを入力してください）

## 注意
- 招待コードは家計の合言葉です。知っている人は家計を見られるので、SNSなどには載せないでください
- 端末のデータを消した・機種変更した場合は、招待コードを入れ直せば元の家計に戻れます
- 「共有」タブの「書き出す」で、ときどきバックアップをとっておくと安心です
- 更新するときは index.html を差し替え、sw.js の CACHE の名前（kakei-v2）を kakei-v3 などに変えてください
